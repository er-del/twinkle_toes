Voice and speech keys Optional

Fish Audio is preferred for voice when its key is saved. Otherwise the server uses its configured NVIDIA voice or local English voice; an NVIDIA chat key is reused for NVIDIA voice. A Groq key can power speech recognition even when another chat provider is selected.

Keys stay in this browser's local storage and are sent to this server to make provider requests. Use HTTPS on shared networks; do not use this local setup as a public multi-user service.
